Course Syllabus

3 Lecture Hours

Unit 1: Introduction to Scientific Computing

Basics of Linux OS, Linux commands, vi and vim editor, algorithms and flowcharts.

10 Lecture Hours

Unit 2: Scientific Programming using FORTRAN 90

Constants, variables, operators, expressions, I/O, branching, loops, arrays, functions, subroutines, disk I/O, modules and user-defined data types.

5 Lecture Hours

Unit 3: Scientific Word Processing

LaTeX documents, classes, compiling, equations, figures, tables, table of contents, bibliography, citation, index, glossary, fonts, colors and errors.

5 Lecture Hours

Unit 4: Visualization and Data Analysis with Gnuplot

Simple plots, plotting data from files, export, multiple datasets, functions, variables, equations and data analysis.

7 Lecture Hours

Unit 5: Numerical Methods

Roots of equations, linear equations, interpolation, differentiation, integration, ODEs using Euler and Runge-Kutta methods, and introductory PDEs.
