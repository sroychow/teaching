Course Overview

This course introduces students to the computational tools used in scientific work. The simulator section focuses mainly on Unit 2: Python, Unit 3: LaTeX, and Unit 4: Data Analysis and Visualization using Gnuplot.

Syllabus

Unit 1: Introduction to LINUX and Scientific Computing

7 Lecture Hours

Basics of LINUX operating system, Linux commands, vi and vim editors. Computer architecture and organization, number systems and arithmetic, floating point representation, underflow and overflow, algorithms, and errors in scientific computations.

Unit 2: Programming with Python

11 Lecture Hours

Python literals, operators, variables, decision making, loops, logic operators, lists, sorting, functions, scopes, tuples and dictionaries, modules and packages, errors and exceptions, strings, basic object programming, file processing, NumPy and Pandas.

Unit 3: Scientific Word Processing

6 Lecture Hours

Introduction to LaTeX; preparing a basic LaTeX file, document classes, compiling LaTeX files, environments, commands, equations, figures, tables, bibliography, and citation.

Unit 4: Data Analysis and Visualization

6 Lecture Hours

Introduction to Gnuplot, basic commands, simple plots, plotting data from files, saving and exporting plots, multiple datasets per file, understanding data, and data analysis with Gnuplot.

Simulator Modules

Unit 2: Python Teaching Simulators

Variables, if-else, loops, functions, lists, plotting logic, NumPy-style arrays, Pandas-style tables, and file processing.

Unit 3: LaTeX Teaching Simulators

Document structure, equations, tables, figures, Beamer slides, bibliography, and citation generation.

Unit 4: Gnuplot and Visualization

Generate basic Gnuplot commands, plot data from files, compare datasets, and export plots.
